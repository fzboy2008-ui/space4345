# AETHER — Beyond the Known
A responsive, interactive space-exploration website made with plain HTML, CSS and JavaScript.

## Publish with GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `style.css`, and `script.js` to the root of your repository.
3. Commit changes.
4. Open **Settings → Pages**, select your branch (usually `main`) and `/root`.
5. Visit the published URL.

No framework, build step, API key, or backend is required. Google Fonts are optional and fall back to system fonts.
