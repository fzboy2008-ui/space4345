# VOID/OS — Personal Digital Space

A responsive interactive browser playground made with vanilla HTML, CSS and JavaScript.

## Included apps
- **Terminal:** commands, time, quotes and a hidden easter egg (`secret`)
- **Memory Vault:** saves notes in browser localStorage on this device
- **Focus Chamber:** 25-minute focus timer
- **Neon Reflex:** reaction-time mini-game with a locally saved personal best

## Deploy
Upload `index.html`, `style.css`, and `app.js` to the root of a GitHub repository. Enable GitHub Pages from Settings → Pages → Deploy from branch → main / root.

No backend, framework, API key or build step is required. Google Fonts are optional; local fallback fonts are included.
